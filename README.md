

\# Postman API Practice



A beginner project to learn API testing with Postman.



\## API

JSONPlaceholder: https://jsonplaceholder.typicode.com/



\## HTTP Methods

\- GET: Retrieve data

\- POST: Create a resource

\- PUT: Update a resource

\- DELETE: Delete a resource



\## Project Files

\- postman-test.http: Sample HTTP requests

\- sample-data.json: Sample JSON request body



\## Learning Goals

\- Understand HTTP requests and responses

\- Practise JSON request bodies

\- Interpret HTTP status codes



Note: JSONPlaceholder simulates write operations; changes are not permanently stored.
